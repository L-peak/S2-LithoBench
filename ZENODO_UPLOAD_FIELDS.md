## Description
This deposit contains the complete, reproducible pipeline and the derived data
tables for the S2-LithoBench benchmark. The benchmark compares four nested
feature sets (spectral bands; spectral indices; terrain attributes; local
texture), five classifiers and two validation protocols (stratified random and
spatially blocked five-fold cross-validation) for lithological mapping in two
arid Australian study areas, using only open data: Sentinel-2 L2A imagery
(Earth Search STAC, Element 84/AWS), the Geoscience Australia 1:1,000,000
surface-geology map (CC BY 4.0), and Copernicus DEM GLO-30 (AWS).

Contents: eight ordered Python scripts (geology download, stratified sampling,
multi-date Sentinel-2 feature extraction, terrain fusion, model comparison,
figures, demonstration map, statistical analysis, robustness battery), sample
tables with all extracted features (n = 2,014 and n = 1,278), metric tables,
confusion matrices, out-of-fold predictions, permutation importances,
repeated spatial-CV results with Wilcoxon/Holm tests, buffered and block-size
sensitivity, geological-unit GroupKFold, class-balanced and polygon-capped
sampling, majority-class and label-shuffled controls, XGBoost results,
transfer confidence intervals, run logs and manuscript figures (PNG + PDF).
All random seeds are fixed (SEED = 42); the full pipeline runs in about
70 minutes on a 16-core desktop without GPU.

Key findings: pixel-wise random validation inflated macro-F1 by 0.16-0.41
relative to spatially blocked validation; terrain attributes produced the only
large incremental gain (+0.079/+0.094, with terrain-only features reaching
0.199/0.279); spectral indices and 3x3 texture contributed at most 0.03;
holding out entire geological units reduced macro-F1 to 0.091/0.109, with
label-shuffled controls at 0.145/0.160; cross-region transfer remained near
chance.
